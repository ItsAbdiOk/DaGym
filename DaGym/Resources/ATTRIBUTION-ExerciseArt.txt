Changes made by DaGym
---------------------
DaGym does not ship the source SVG files. Instead, each frame's single vector path
(the `d="..."` attribute) is extracted and packed into one zlib-compressed data file
(ExerciseArtPaths.zlib, see scripts/import-exercise-art.swift). Three changes were made
to the licensed material:

1. Coordinate precision. Every decimal coordinate in the path data is rounded to 1
   decimal place, against the artwork's 512x512 viewBox.

2. Elliptical arcs are flattened. At display time the path data is drawn by the
   vendored MuscleMap renderer (DaGym/Vendor/MuscleMap/Core/PathBuilder.swift), which
   draws every SVG elliptical-arc command ("A"/"a") as a straight line to the arc's
   end point. All 9,031 arcs across the 516 shipped frames are therefore rendered as
   straight chords rather than curves, so curved details are subtly flattened.

3. Colour. Each frame is filled with a single solid colour (DGColor.ink2 — near-black
   in light appearance, near-white in dark appearance), replacing the artwork's
   original fill. The fill does not follow the user's accent colour.

No other changes were made to the linework.

Scope of use
------------
Only the illustrated artwork and its accompanying exercise metadata (names, slugs,
frame ordering) from Bryl Lim's "workout-guide" package are used. None of that
package's source code is used anywhere in DaGym.
